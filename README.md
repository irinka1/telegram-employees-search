# Telegram Employee Search Bot

Telegram-бот с мини-приложением для рекрутеров: ищет резюме кандидатов сразу на нескольких украинских джоб-бордах по нескольким должностям и городам одновременно, а затем сам следит за новыми откликами.

## Возможности

- **Мультипоиск.** В мини-приложении можно добавить несколько пар "должность + город" кнопкой "+" и запустить поиск по всем сразу.
- **Два источника данных.** `work.ua` — через публичный текстовый рендер; `robota.ua` — через headless-браузер (Puppeteer + stealth-плагин), потому что сайт отдаёт резюме через JS и не пропускает обычные HTTP-запросы.
- **Почасовой автопоиск.** После первого запроса бот сам проверяет новые резюме раз в час и присылает только то, что появилось.
- **Гибкое управление подписками.** Меню-кнопки в чате: новый поиск, список активных запросов, точечная остановка поиска по конкретной должности (без сброса остальных).
- **Уведомления менеджеру.** Отдельный админ-чат получает сводку по каждому новому поиску: кто искал и по каким должностям.
- **Anti-spam.** Rate limiting на чат и на IP для API мини-приложения.

## Технологии

Node.js · Express · Telegraf · Puppeteer-extra (+ stealth) · Axios

## Архитектура

```
public/           — Telegram Mini App (форма с динамическим списком должностей)
src/server/       — Express-сервер, отдаёт мини-апп и принимает поиск через /api/search
src/bot/          — Telegram-логика: команды, меню-кнопки, почасовые подписки
src/services/     — Парсинг резюме с work.ua и robota.ua
```

## Запуск

```bash
npm install
cp .env.example .env   # заполнить своими значениями
npm start
```

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `MINIAPP_URL` | публичный HTTPS-адрес мини-аппа |
| `RESUME_POLL_INTERVAL_MS` | интервал почасовой проверки новых резюме (по умолчанию 3600000 = 1 час) |
| `ADMIN_CHAT_ID` | чат менеджера для уведомлений о новых поисках |
| `SEARCH_RESULTS_PER_SOURCE` | сколько кандидатов брать с каждого источника |
| `SEARCH_TIMEOUT_MS` | таймаут запроса к источникам |
| `RATE_LIMIT_WINDOW_MS`, `RATE_LIMIT_MAX`, `BAN_DURATION_MS` | защита от спама и флуда |

## Команды и меню

- `/start`, `/find` — открыть мини-приложение
- 🔎 Новий пошук — остановить все текущие поиски и начать заново
- 📋 Перелік резюме, які вже в пошуку — список активных запросов
- 🛑 Зупини пошук — остановить поиск по конкретной должности
- `/stop_updates` — остановить всё автообновление разом

## Важное про источники

- `robota.ua` анонимным посетителям показывает только часть найденных резюме (остальное — после регистрации работодателя). Бот не логинится под аккаунтом и использует исключительно то, что видно без входа.
- `olx.ua` в разделе "Робота" не публикует резюме соискателей (только вакансии от работодателей), поэтому не подключён как источник.

## Деплой

Разворачивается как обычный Node-процесс (systemd) за nginx-реверс-прокси с HTTPS (Let's Encrypt). Puppeteer требует установленного Chromium и системных библиотек на сервере (`libnss3`, `libatk-bridge2.0-0`, `libgbm1` и т.д.).
