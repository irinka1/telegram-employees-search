# Поиск сотрудников через Telegram

Мини-приложение и Telegram-бот для поиска кандидатов на украинских сайтах.

## Что делает

- Пользователь заполняет:
  - одну или несколько пар "должность + город" (кнопка "+ Добавить должность"),
  - вид занятости (общий для всех должностей),
  - минимальный опыт на должности (опционально).
- Бот ищет кандидатов на `work.ua` и `robota.ua` (анонимно доступная часть резюме, без входа в аккаунт).
- В ответ присылает:
  - ФИО,
  - возраст,
  - фото,
  - должность,
  - опыт на должности,
  - ссылку на резюме.
- После первого поиска бот раз в час (настраивается) сам проверяет новые резюме по тем же запросам и присылает только новые. Остановить командой `/stop_updates`.

## Запуск

```bash
npm install
npm start
```

Перед запуском заполните `.env` по примеру `.env.example`.

## Важное

- `work.ua` отдаёт публичный текст резюме через text-mirror (r.jina.ai).
- `robota.ua` требует реальный браузер (Puppeteer) — резюме там подгружаются JS-ом, а анонимному посетителю сайт сам показывает только часть найденных резюме (остальные скрыты до регистрации работодателя). Бот не логинится под аккаунтом — использует только то, что видно без входа.
- `olx.ua` в разделе "Робота" не публикует резюме соискателей (только вакансии от работодателей), поэтому как источник не подключён.
- `RESUME_POLL_INTERVAL_MS` задаёт интервал почасовой проверки новых резюме (по умолчанию 3600000 = 1 час).
- Если источник не отдаёт карточку, бот просто пропустит его и продолжит поиск по другим сайтам.

## Структура

- `bot.js` - точка входа
- `src/app.js` - запуск бота и HTTP-сервера
- `src/bot/createBot.js` - Telegram-логика, сборка результатов по нескольким должностям
- `src/bot/subscriptions.js` - почасовое отслеживание новых резюме по чату
- `src/server/` - API и раздача мини-приложения
- `src/services/search.js` - поиск и парсинг кандидатов (work.ua + robota.ua через Puppeteer)
- `public/` - интерфейс mini app (динамический список должностей)
